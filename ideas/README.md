# Adventure Ideas Repository

## IMPORTANT DISCLAIMER

This folder contains **preliminary adventure concepts and brainstorming materials** that are:
- NOT part of the official campaign narrative
- NOT canon to the established story
- Subject to contradictions with existing lore
- In various stages of development from rough concepts to detailed outlines
- May be abandoned, merged, or completely rewritten

**These are working documents for referee planning purposes only.**

## Purpose

This repository serves as a creative sandbox for:
- Brainstorming future adventure concepts
- Exploring "what if" scenarios
- Storing partially developed ideas for later refinement
- Testing adventure structures before full implementation

### Development Stages

- **Initial Concept**: Basic premise and inspiration noted, minimal detail
- **Partial Outline**: Some sections developed, key NPCs or locations sketched
- **Detailed Outline**: Full adventure structure with NPCs, locations, complications, and outcomes
- **Ready to Run**: Fully developed with mechanics, maps, and referee notes (none currently at this stage)

### Notes

- Ideas may reference non-existent NPCs, ships, or locations
- Mechanical details may not be fully developed
- Plot elements may conflict with established campaign events
- Consider all content here as "draft" status until moved to proper adventure directories
- Adventures may be combined, split, or heavily modified before implementation
- Inspiration sources are noted but adventures should develop their own unique identity

### Usage Guidelines

1. **For Referee Planning**: Use these as starting points for session preparation
2. **Not Player-Facing**: These documents contain spoilers and meta-information
3. **Modification Expected**: Adapt to fit current campaign state and player interests
4. **Cross-Pollination Encouraged**: Elements from different concepts can be combined
5. **Canon Flexibility**: Nothing here is set in stone until actually played

### File Naming Convention

- All adventure concepts follow the pattern: `adventure-[name].md`
- Names should be concise and evocative (2-3 words maximum)
- All files should include inspiration source in subtitle for reference
