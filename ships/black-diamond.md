# Black Diamond (Modified Free Trader)

## Registry

## Description
A heavily modified Free Trader built for dangerous frontier routes. Every system has been upgraded for survival in hostile space. The concealed cargo compartment and military-grade defenses suggest the previous owner's involvement in less-than-legal activities along the Zhodani border.
