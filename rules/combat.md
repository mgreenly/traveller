## Combat Overview (Core Rules p.73)

Combat is divided into **6-second rounds**. Each participant acts once per round in initiative order.

### Basic Combat Sequence
1. Determine surprise (if applicable)
2. Roll initiative  
3. Participants act in initiative order
4. Repeat steps 3 until combat ends

## Initiative and Turn Order (Core Rules p.73)

### Rolling Initiative
**2D + DEX DM** (or INT DM if ambushing/tactical advantage) (Core Rules p.73)

### Turn Order  
1. Highest initiative acts first
2. Ties act simultaneously (highest DEX goes first if still tied)
3. Continue in descending order
4. Repeat each round

### Ambushes (Core Rules p.73)
- Aware side gains **DM+6** to Initiative (first round only)
- Unaware side suffers **DM-6** to Initiative (first round only)

### Tactics (Core Rules p.73)
- One character per side may make a Tactics check at combat start
- Effect applies to all allies' Initiative

## Combat Actions (Core Rules p.73-75)

Each turn, a combatant can perform:
- **1 Significant Action** + **1 Minor Action**, OR  
- **3 Minor Actions**
- **Plus:** Unlimited Reactions and Free Actions

### Significant Actions (Core Rules p.74-75)
- **Attack:** Make one attack (Core Rules p.74)
- **Leadership:** INT/EDU/SOC + Leadership check (Core Rules p.74)
- **Miscellaneous:** Any action requiring full attention (Core Rules p.75)
  - Examples: First aid, bypassing security, using psionics, getting into vehicle crew position

### Minor Actions (Core Rules p.75)
- **Aim:** +1 DM to next attack (max +6) (Core Rules p.75)
- **Change Stance:** Stand/crouch/prone (Core Rules p.75)
- **Draw/Reload:** Ready, stow, or reload a weapon (Core Rules p.75)
- **Movement:** Move up to Movement score (6m for humans) (Core Rules p.75)
- **Take Cover:** Move to available cover to gain -2 DM protection against ranged attacks
- **Miscellaneous:** Actions not requiring full attention (Core Rules p.75)

### Reactions (Not an Action)
**You can perform an unlimited number of Reactions per combat round** (Core Rules p.74-76)
- Each Reaction gives you **DM-1 on your next set of actions**
- Reactions accumulate: 2 reactions = DM-2, 3 reactions = DM-3, etc.

**Types of Reactions:**
- **Dodge:** Inflict penalty equal to DEX DM or Athletics (dexterity), whichever is higher, on attacker's roll (Core Rules p.76)
- **Parry:** Inflict your Melee skill as negative DM to attacker's melee attack roll (Core Rules p.76)
- **Dive for Cover:** (Core Rules p.76)
  - DM-2 to all ranged attacks this round
  - May dive to any cover within 1.5 metres
  - If no cover available: only DM-1 (for being prone)
  - Forfeit next actions completely

### Extended Actions (Core Rules p.75)
Some actions take longer than one round:
- Roll for timeframe (Core Rules p.62)
- If damaged during Extended Action: skill check with damage as negative DM
- Failure by Effect -6 or worse ruins the task completely

### Free Actions (Core Rules p.75)
Actions so quick they don't warrant a Minor Action:
- Shouting a warning
- Pushing a button
- Simple communication
- Dropping an item

## Attack Resolution

### Basic Attack Roll (Core Rules p.74)
**2D + Skill + Characteristic DM ≥ 8**

### Gun Combat Attack (Core Rules p.74)
1. **Roll:** 2D + DEX DM + Gun Combat (Core Rules p.74)
2. **Modifiers:** (Core Rules p.74)
   - Range (see Range Bands below)
   - Aim bonus (+1 per aim, max +6)
   - Cover (-2)
   - Target stance (prone -1)
3. **Success:** Roll damage

### Melee Attack (Core Rules p.74, p.77)
1. **Roll:** 2D + STR or DEX DM + Melee (Core Rules p.74)
2. **Modifiers:**
   - Opponent can parry (inflicts Melee skill as negative DM)
   - Size difference modifiers
3. **Success:** Roll damage + STR DM + Effect (Core Rules p.77)

### Range Bands (Weapon-Specific)
**Based on weapon's Range score:** (Core Rules p.76-77)
- **Short Range (≤¼ of Range):** +1 DM
- **Effective Range (¼ to full Range):** +0 DM
- **Long Range (1-2× Range):** -2 DM
- **Extreme Range (2-4× Range):** -4 DM
- **Note:** Without Scope trait, attacks >100m are automatically Extreme Range

**Encounter Range Bands (for reference):** (Core Rules p.83)
- Close: 0-5m
- Short: 5-10m
- Medium: 11-50m
- Long: 51-250m
- Very Long: 251-500m
- Distant: 501-5,000m

## Damage and Armor

### Applying Damage
1. Roll weapon damage
2. Add Effect from attack roll to damage total
3. Subtract armor protection
4. Apply to characteristics
5. **Note:** Attack with Effect 6+ always inflicts at least 1 damage regardless of armor (Core Rules p.77)

### Damage Allocation (Core Rules p.77)
**For each attack that causes damage:**
1. All damage is initially applied to END
2. If END reaches 0, excess damage goes to either STR or DEX (target's choice)
3. If two characteristics reach 0, remaining damage goes to the last characteristic  
4. If all three physical characteristics reach 0, character dies

Example: Taking 7 damage with END 4, STR 8, DEX 6:
- 4 damage reduces END to 0
- 3 excess damage goes to STR or DEX (target chooses)
- If target chooses DEX: DEX becomes 3

### Characteristic Damage Effects (Core Rules p.77)
- **First characteristic at 0:** Wounded but functional
- **Two characteristics at 0:** Unconscious
- **Three characteristics at 0:** Dead

### Armor (Core Rules p.77)
- Reduces damage by protection value
- Does not stack (use highest value)
- May have DM penalties to DEX
- AP (Armor Piercing) weapons ignore armor equal to AP score (Core Rules p.79)

### Destructive Damage (Core Rules p.78)
- Noted as DD (e.g., 3DD = Destructive, rolling 3 dice)
- **Multiply damage roll by 10**
- Used for anti-vehicle and spacecraft weapons
- Can destroy small vehicles with a single shot

## Special Situations

### Cover
- **In Cover (-2 to hit):** Using cover while engaging in combat (Core Rules p.77)
- **Hiding Behind Cover:** Gain bonus Protection based on cover type (Core Rules p.77-78):
  - Vegetation: +2 Protection
  - Tree Trunk: +6 Protection  
  - Stone Wall: +8 Protection
  - Civilian Vehicle: +10 Protection
  - Armoured Vehicle: +15 Protection
  - Fortifications: +20 Protection

### Grenades
1. **Throw:** DEX + Athletics (dexterity), range = STR × 3 meters
2. **Miss:** Scatters 1D meters in random direction
3. **Damage:** All within blast radius (Blast trait - Core Rules p.79)

### Grappling (Core Rules p.78)
1. **Initiate:** Opposed Melee (unarmed) checks using STR or DEX DM
2. **Winner can choose to:**
   - Force opponent prone
   - Disarm opponent (Effect 6+ = take their weapon)
   - Throw opponent 1D metres (causes 1D damage, ends grapple)
   - Inflict 2 + Effect damage (ignores armor)
   - Inflict damage with pistol or small blade
   - Escape and move away (ends grapple)
   - Drag opponent up to 3 metres
   - Continue grapple
3. **While Grappled:** Cannot perform any actions except opposed Melee (unarmed) checks

### Dual Weapons (Core Rules p.78)
- May use two one-handed weapons (pistols, blades)
- Can attack with both in same round
- Cannot aim with either
- **DM-2 to both attack rolls**
- No penalty if carrying two but only attacking with one

### Melee Combat (Close Combat) (Core Rules p.76)
When within 2 metres:
- Locked in close combat
- Only pistols can make ranged attacks (can be parried)
- Rifles can only be used as clubs
- Moving away grants opponent free attack at DM+2

### Combat Example
1. **Determine Initiative:** 2D + DEX DM (Core Rules p.73)
2. **Combat Round:** Each participant acts in Initiative order
3. **Making an Attack:**
   - Declare target
   - Target may declare Reaction
   - Roll 2D + skill + characteristic DM ≥ 8
   - If hit: Roll damage + Effect, subtract armor
4. **Continue** until combat ends
