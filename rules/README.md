## Usage Notes

These tables and references are designed for quick lookup during gameplay:
- Combat and medical rules provide essential mechanics for dangerous situations
- Starship operations guides cover the financial and technical aspects of ship ownership
- Travel references help calculate journey times and understand system restrictions
- Law level and travel zone information assists in planning adventures and encounters
- Equipment lists provide standard gear availability and costs

**IMPORTANT:** For any rules question, always check this directory first before accessing the complete rule books in the `books/` directory to minimize context usage.
